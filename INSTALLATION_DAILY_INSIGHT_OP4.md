# Installation — Daily Insight OP4

1. Importer les fichiers du ZIP en conservant leur arborescence.
2. Déployer le Worker depuis Cloudflare.
3. Ouvrir `/daily-insight-op4-gallery?city=tarnos`.
4. Vérifier la décision réelle du jour et les huit scénarios de contrôle.

Aucune requête SQL supplémentaire n’est nécessaire.

L’OP4 ne modifie pas le moteur Daily officiel, ses publications, ses crons ou ses options d’activation. Elle reste une galerie de laboratoire avec export manuel uniquement.
