LOKA V24 — BLOC 12.13
=======================

-----
Mécanisme FINAL de GO LIVE V24 / Instagram.

Installer le Bloc 12.13 N'ACTIVE PAS V24.

Dans l'état actuel NOT_READY, le panneau GO LIVE affichera BLOCKED et aucune
écriture moteur ne sera effectuée.

POURQUOI GLOBAL ROLLBACK CHANGE EN 12.13
-----------------------------------------
Avant 12.13, la production réelle restait Legacy pendant les drills.

Après un vrai GO LIVE, un simple :
requested_mode = LEGACY
ne suffit plus.

Le forecast public courant peut déjà être V24.

Le rollback 12.13 fait donc désormais deux choses :

1. désarme immédiatement V24 dans engine_control ;
2. si le produit public stocké est V24, restaure immédiatement le backup
   Legacy persistant comme produit public courant.

Le rollback reste prioritaire :
une panne d'audit ne peut jamais empêcher le retour de engine_control à Legacy.

ANCIEN WORKFLOW D'AUTORISATION
------------------------------
Les routes historiques :

POST /api/admin/engine/approval/prepare
POST /api/admin/engine/approval/confirm

sont désormais verrouillées en écriture.

Elles ne peuvent plus être utilisées pour contourner le Bloc 12.13.

Toute activation officielle passe exclusivement par :

GET  /api/admin/go-live
POST /api/admin/go-live/prepare
POST /api/admin/go-live/confirm

PRÉREQUIS GO LIVE — TOUS BLOQUANTS
-----------------------------------
Le serveur exige simultanément :

1. Production publique actuelle = LEGACY
2. requested_mode = LEGACY
3. v24_approved = NON
4. aucun ancien challenge V24 PENDING
5. readiness = READY_CANDIDATE
6. FINAL_RC_PASS correspondant EXACTEMENT à la génération courante
7. REHEARSAL_PASS correspondant EXACTEMENT :
   - à la même génération
   - au même fingerprint
   - au FINAL_RC_PASS courant
8. backup Legacy persistant vérifiable
9. candidat V24 constructible
10. master physique du candidat accessible
11. garde-fou de génération complet = PASS :
    - >= 4 modèles
    - score >= 55
    - confiance MEDIUM/HIGH
    - écart gagnant/runner-up suffisant
    - preuves brouillard/orage si nécessaires
    - master disponible
    - payload V24 valide

Un seul FAIL = aucune activation.

CURRENT NOT_READY
-----------------
Avec le readiness actuel NOT_READY, le résultat attendu après installation est :

GO LIVE V24 — contrôle final
BLOCKED

Readiness requis   READY_CANDIDATE
Readiness actuel   NOT_READY

Aucune mutation de production.

DOUBLE CONFIRMATION FINALE
--------------------------
Quand tous les contrôles deviennent PASS :

Étape 1
-------
"Préparer GO LIVE · confirmation 1 / 2"

Le serveur crée un snapshot immuable valable 10 minutes.

Le snapshot contient notamment :
- génération publique
- fingerprint public
- readiness + fingerprint
- FINAL_RC audit
- REHEARSAL audit
- candidat V24
- master
- garde-fou complet

Étape 2
-------
Il faut taper exactement :

ACTIVER V24 OFFICIEL TARNOS

Puis une confirmation navigateur finale est demandée.

Si la génération, le readiness ou une preuve change entre les deux étapes :
confirmation REFUSÉE.

ACTIVATION
----------
Après confirmation valide :

1. engine_control est armé :
   requested_mode = V24
   v24_approved = 1

2. un événement APPROVED compatible avec activationGuard est écrit dans
   engine_activation_audit.

3. LOKA lance IMMÉDIATEMENT une nouvelle génération météo :
   source = go_live_12_13

4. Cette nouvelle génération passe à nouveau tous les garde-fous réels.

CAS A — GARDE-FOU PASS
----------------------
Le forecast est publié V24.

Puis le resolver public est vérifié.

Résultat :
GO_LIVE_ACTIVE

À partir de ce moment :
- / = Dashboard V24 officiel
- /instagram = Studio Instagram V24 officiel
- /api/latest = V24
- /api/decision = V24

Aucune publication automatique n'est envoyée sur Instagram :
le Studio officiel devient simplement le produit V24 à utiliser pour la
publication manuelle.

CAS B — GARDE-FOU DE LA NOUVELLE GÉNÉRATION FAIL
-------------------------------------------------
La génération reste Legacy grâce au fallback par génération.

Le GO LIVE est immédiatement ABORTED.

engine_control revient Legacy.

Résultat :
GO_LIVE_ABORTED

CAS C — V24 ÉCRIT MAIS SURFACE PUBLIQUE NON VÉRIFIÉE
-----------------------------------------------------
Le rollback global 12.13 :
- désarme V24 ;
- restaure le backup public Legacy.

Une activation non vérifiée n'est jamais marquée ACTIVATED.
