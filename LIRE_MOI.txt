LOKA V24 — BLOC 11.1
======================

OBJECTIF
--------
Installer le plan de contrôle du futur sélecteur de moteur et le rollback
SANS connecter V24 à forecast.scene.

INVARIANT ABSOLU DE CE SOUS-BLOC
--------------------------------
effectiveProduction = LEGACY

Même si :
- requested_mode = V24
- readiness = READY_CANDIDATE
- une décision V24 valide existe

Bloc 11.1 ne contient aucune voie permettant de publier V24.

FICHIERS
--------
AJOUTER :
- migrations/0003_engine_control.sql
- src/engine/engineMode.ts
- src/storage/engineControl.ts

REMPLACER :
- src/index.ts
- src/ui/dashboard.ts

MIGRATION
---------
Créer engine_control, une ligne par ville.

État initial Tarnos :
requested_mode = LEGACY
v24_approved = 0

ROUTES ADMIN
------------
GET  /api/admin/engine?city=tarnos
POST /api/admin/engine/preview?city=tarnos
POST /api/admin/engine/request-v24?city=tarnos
POST /api/admin/engine/rollback?city=tarnos

Toutes nécessitent ADMIN_TOKEN.

PREVIEW
-------
/preview persiste requested_mode = V24_PREVIEW.
La production reste LEGACY.
previewEnabled indique seulement si une décision V24 valide est disponible.

TEST DU DOUBLE VERROU
---------------------
/request-v24 persiste l'intention V24 avec v24_approved = 0,
puis retourne HTTP 423 :
production_activation_locked_bloc_11_1

Cette route existe uniquement pour prouver qu'une intention V24 ne suffit pas.

ROLLBACK
--------
/rollback :
- requested_mode = LEGACY
- v24_approved = 0
- approved_at/by = NULL
- rollback_at = maintenant
- rollback_reason = raison fournie

Le rollback ne dépend PAS de shadow_history ni de readiness.

ADMIN MOBILE
------------
Nouveau bloc "Moteur météo" avec :
- moteur officiel effectif
- mode demandé
- Preview active/inactive
- readiness
- raison de résolution
- état d'approbation
- dernier rollback
- bouton Activer Preview V24
- bouton Revenir à Legacy
- bouton de test demande V24 production (doit être refusé)

ORDRE D'INSTALLATION
--------------------
1. Ajouter/remplacer les fichiers.
2. Appliquer migrations/0003_engine_control.sql sur D1 distant.
3. Déployer.
4. /admin -> Contrôler le moteur.
5. Vérifier : Production = LEGACY.
6. Activer Preview -> Production doit rester LEGACY.
7. Tester demande V24 -> doit être refusée.
8. Rollback -> requested_mode revient LEGACY.

IMPORTANT
---------
Ne pas ajouter SCENE_ENGINE_MODE=V24 dans Cloudflare pour le moment.
Ce sous-bloc permet de tester le contrat de sécurité sans aucune bascule.
