NOUVELLE ICONOGRAPHIE
---------------------
La palette fournie devient la référence graphique.
Tous les pictogrammes restent vectoriels Canvas, monochromes #12264A,
sans emoji système et sans remplissage.

Familles intégrées :
- nuage / couvert ;
- soleil ;
- éclaircies / variable ;
- pluie ;
- bruine ;
- orage ;
- brouillard / brume ;
- vent ;
- neige / gel ;
- nuage + vent ;
- pluie + vent ;
- soleil + vent.

IMPORTANT
---------
L'heure n'a AUCUN effet sur le pictogramme météo.
À 22h, le visuel représente la condition réelle : soleil, nuage, pluie,
orage, vent, brouillard, etc. Aucune lune n'est injectée automatiquement.

BOX MÉTÉO GÉNÉRALE
-------------------
La petite phrase est maintenant clairement centrée sous l'ensemble
pictogramme + titre. Le décalage est volontairement plus marqué que dans
la 12.16.10 afin que la modification soit perceptible.

Référence :
- icône : x=172 / y=332 ;
- titre : x=302 / baseline y=350 ;
- sous-titre : center x=505 / baseline y=438 ;
- sous-titre : largeur max 610 px ;
- mini/maxi : x=976 / baseline y=374.
