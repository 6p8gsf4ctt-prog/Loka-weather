CORRECTION BLOQUANTE
--------------------
Le JavaScript du Canvas est contenu dans une template string TypeScript.
Les expressions régulières internes doivent donc doubler les antislashs.

Exemple source TypeScript :
  /\\s+/g

JavaScript réellement envoyé au navigateur :
  /\s+/g

La version précédente pouvait envoyer /s+/g et remplacer toutes les lettres
« s » par des espaces, puis déclencher le diagnostic de texte et interrompre
le rendu avant le chargement du master.

La FINAL VERIFIED :
- corrige tous les échappements \s / \d concernés ;
- rend le diagnostic texte non bloquant ;
- expose window.__LOKA_RENDER_STATUS pour le contrôle navigateur ;
- capture toute erreur de draw() sans rejet Promise non géré.

CORRECTIF MÉTÉO 22H — WEATHER ICONS ONLY
----------------------------------------
Les pictogrammes horaires ne dépendent plus de l'heure du jour.
22h utilise exactement la même logique météo que 04h, 06h, 12h, etc.

Exemples :
- soleil / ciel clair -> soleil ;
- peu nuageux / éclaircies -> soleil + nuage ;
- nuageux / couvert -> nuage ;
- pluie / averses -> pluie ;
- orage -> orage ;
- brouillard -> brouillard ;
- vent -> vent.

Aucune lune et aucun pictogramme nocturne ne sont sélectionnés par l'heure.
La box solaire reste évidemment inchangée.
