# LOKA Daily Insight — OP4

## Objectif

L’OP4 transforme la détection technique de l’OP3 en une véritable décision éditoriale Instagram. Elle reste intégralement isolée du moteur Daily officiel.

## Route

`/daily-insight-op4-gallery?city=tarnos`

Une date de contrôle peut être ajoutée :

`/daily-insight-op4-gallery?city=tarnos&date=2026-09-30`

## Quatre structures

1. **Niveau rare** : record, dernière occurrence ou percentile local.
2. **Bascule horaire** : évolution rapide et perceptible en quelques heures.
3. **Série locale** : séquence observée ou enchaînement remarquable.
4. **Repère utile** : événement certain, pratique ou spécifiquement local.

## Hiérarchie éditoriale

- seuil général : 70/100 ;
- variation de pression générique `A01` : 80/100 minimum ;
- analogue historique générique `H01` : 78/100 minimum ;
- les niveaux P0 et P1 restent prioritaires ;
- les pénalités de répétition sur sept jours restent actives ;
- un signal sous son seuil propre entraîne un silence éditorial.

Une donnée exacte n’est donc plus automatiquement considérée comme Instagrammable.

## Sécurité

- aucune publication automatique ;
- export PNG manuel uniquement ;
- aucune lecture ou écriture dans les tables Daily officielles ;
- écritures limitées aux caches Daily Insight du laboratoire ;
- aucune modification des crons ou des flags du moteur actif.
